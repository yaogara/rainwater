# Rainwater Directory — Agent Mission & Strategic Charter

## Primary Objective

> **MAXIMIZE SUSTAINABLE NON-BRANDED ORGANIC SEARCH TRAFFIC.**

All technical, architectural, editorial, and link-building operations must serve this primary objective. Monetization and direct revenue optimization will be introduced only after a durable organic search moat has been established.

---

## Core Philosophy & Guardrails

1. **Domain Value Over Page Count**:
   - Long-term domain authority, user trust, and index health supersede raw URL volume.
   - We do not measure progress by how many pages were published; we measure progress by indexed pages generating meaningful impressions, clicks, and intent fulfillment.

2. **Zero Tolerance for Hallucination & Synthetic Data**:
   - Every contractor name, phone number, address, license status, rainfall statistic, rebate figure, and code requirement must originate from authoritative primary sources.
   - Fabricated content undermines domain equity and leads directly to search quality penalties.

3. **Earned Authority Through Utility**:
   - The directory must be a utility, not an ad farm. We provide verifiable data: historical rainfall normals (NOAA), state plumbing codes, actual local contractor profiles, sizing calculators, and unbiased filtration guides.

4. **Iterative Autonomous Execution**:
   - Continuous auditing: measure search console performance, identify position 4–20 strike-zone queries, optimize underperforming URLs, consolidate cannibalized pages, and expand topical clusters methodically.
