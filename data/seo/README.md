# SEO opportunity data

`raw/` preserves dated source exports. `source-manifest.json` records SHA-256 hashes so Hermes can detect accidental changes. `opportunities.csv` is the working queue.

Historical volume and difficulty are research inputs, not publication instructions or current traffic. CPC values from the 2025 Numbers export are zero-coded and must not be used for revenue estimates. Before the site has meaningful Search Console data, prioritize useful gaps in existing pages. Afterwards, update the GSC columns and prefer existing URLs with impressions, achievable positions, and clear intent.

Every queue item needs a distinct intent, one owning URL, required primary sources, a proposed change, and a measured outcome. Never create a page solely because a keyword variant exists.
